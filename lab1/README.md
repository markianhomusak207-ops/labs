## Лабораторна робота №1 (Варіант )

Дано масив цілих чисел `numbers` та ціле число `k`. 
Знайдіть `k`-й найбільший елемент у масиві та його індекс. 
Якщо розмір масиву менший за `k`, програма має повертати помилку.

**Приклад:**
Вхідний масив: `[15, 7, 22, 9, 36, 2, 42, 18]`, `k = 3`
Результат: `22` (індекс `2`)

### Реалізація:
Програма реалізована на мові Python з використанням бібліотеки `unittest` для автоматичного тестування коректності алгоритму.
