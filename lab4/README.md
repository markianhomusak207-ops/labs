## Лабораторна робота №4 (Варіант 13)

**Дано** структуру даних AVL-дерево. Реалізуйте на її основі чергу з пріоритетом, де кожен елемент має значення `value` та пріоритет `priority`. 

Програма повинна підтримувати:
- Додавання елементів з довільним пріоритетом.
- Видалення елемента з найвищим пріоритетом за логарифмічний час $O(\log n)$.
- Балансування дерева (ліві та праві повороти) для збереження ефективності операцій.

**Приклад:**
Додано: `(A, 3), (B, 7), (C, 5), (D, 9)`
Результат `pop()`: Поверне `(D, 9)`, оскільки пріоритет найвищий.
