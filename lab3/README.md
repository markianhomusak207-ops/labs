## Лабораторна робота №3 (Варіант рівеь3 вар 3)

Реалізація алгоритму візуалізації бінарного дерева в консолі. Програма вираховує висоту дерева 
та будує його графічне представлення, відображаючи вузли та зв'язки між ними для наочного аналізу структури.
